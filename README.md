# 아이디어 공장

키워드를 덱에 넣어 두고 무작위로 뽑아 조합하는 브레인스토밍 웹페이지.

**바로 쓰기 → https://kongchu2.github.io/brainstorming/**

## 이렇게 써요

1. 덱을 만들고 키워드를 넣어요. Enter나 쉼표로 하나씩, 여러 개를 붙여 넣으면 나눠서 들어가요.
2. 뽑을 덱을 켜고, 덱마다 몇 장 뽑을지 정해요.
3. `뽑기`(`Cmd+Enter` / `Ctrl+Enter`)를 누르면 켠 덱마다 정한 장 수만큼 쪽지가 나와요.
4. 떠오른 생각은 메모로 남기고, 마음에 드는 조합은 `핀 고정`해요. 다음 뽑기로 넘어가면 지금 조합은 자동으로 기록에 남아요.

## 기능

- **이것만 다시**: 쪽지 하나만 다시 뽑아요. `고정`해 둔 쪽지는 다음 뽑기에도 그대로 남아요.
- **쪽지 빼기**: 쪽지의 ×는 덱은 그대로 두고 이번 조합에서만 빼요.
- **키워드 제외**: 덱의 키워드를 누르면 이번 뽑기에서만 빠져요.
- **이미 나온 조합 제외**: 기록에 있는 조합은 다시 나오지 않아요.
- **기록**: 지난 조합을 다시 열거나, 나중에 메모를 덧붙일 수 있어요. 핀 고정한 기록은 맨 위에 모이고 `기록 삭제`에도 지워지지 않아요.
- **덱 공유**: 켠 덱과 지금 조합을 링크로 복사해요. 받은 사람의 덱은 덮어쓰지 않아요.
- 시스템 / 라이트 / 다크 테마, 애니메이션 최소화

## 데이터

서버 없이 브라우저만으로 동작해요(빌드 도구 없음). 덱과 기록은 브라우저의 localStorage에만 저장되므로, 다른 기기나 브라우저와는 공유되지 않아요. 덱을 옮기려면 `덱 공유`를 쓰세요.

## 로컬에서 열기

ES 모듈을 쓰기 때문에 파일을 바로 열면(`file://`) 동작하지 않아요. 로컬 서버로 여세요.

```sh
python3 -m http.server 8765
# http://localhost:8765/
```

`keyword-draw.html`을 고친 뒤에는 `./build.sh`로 `index.html`을 다시 만들어요.
