# 아이디어 공장

키워드를 덱에 넣어 두고 무작위로 뽑아 조합하는 브레인스토밍 웹페이지.

**바로 쓰기 → https://kongchu2.github.io/brainstorming/**

## 이렇게 써요

최근 생긴 취미나 평소에 관심있던 것들, 머릿속에 떠오르는 단어들을 덱에 적어 넣어요.
뽑기를 하면 적어 넣은 단어들이 랜덤하게 뽑혀 나와요.
랜덤한 조합에서부터 떠오르는 아이디어를 발전시켜 보세요.

## 데이터

서버 없이 브라우저만으로 동작해요(빌드 도구 없음). 덱과 기록은 브라우저의 localStorage에만 저장되므로, 다른 기기나 브라우저와는 공유되지 않아요. 덱을 옮기려면 `덱 공유`를 쓰세요.

## 로컬에서 열기

ES 모듈을 쓰기 때문에 파일을 바로 열면(`file://`) 동작하지 않아요. 로컬 서버로 여세요.

```sh
python3 -m http.server 8765
# http://localhost:8765/
```

`keyword-draw.html`을 고친 뒤에는 `./build.sh`로 `index.html`을 다시 만들어요.
