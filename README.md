# 아이디어 공장

키워드를 덱에 넣어 두고 무작위로 뽑아 조합하는 브레인스토밍 웹페이지.

**바로 쓰기 → https://kongchu2.github.io/brainstorming/**

## 이렇게 써요

1. 덱을 만들고 키워드를 넣어요. Enter나 쉼표로 하나씩, 여러 개를 붙여 넣으면 나눠서 들어가요.
2. 뽑을 덱을 켜고, 덱마다 몇 장 뽑을지 정해요.
3. `뽑기`(`Cmd+Enter` / `Ctrl+Enter`)를 누르면 켠 덱마다 정한 장 수만큼 쪽지가 나와요.
4. 마음에 드는 조합은 메모를 남기고 `기록하기`를 누르거나 ★ 후보로 표시해요.

## 기능

- **관점 카드**: 켜 두면 뽑을 때마다 "키워드를 어떻게 비틀지" 정하는 카드가 한 장 붙어요.
- **이것만 다시**: 쪽지 하나만 다시 뽑아요. `고정`해 둔 쪽지는 그대로 남아요.
- **이미 나온 조합 제외**: 기록에 있는 조합은 다시 나오지 않아요.
- **기록**: 메모와 ★ 후보로 걸러 보고, 마크다운으로 복사할 수 있어요.
- **링크 공유**: 덱과 지금 조합을 주소에 담아 보내요. 받은 사람의 덱은 덮어쓰지 않아요.
- 라이트 / 다크 테마

## 데이터

서버 없이 브라우저만으로 동작해요(빌드 도구 없음). 덱과 기록은 브라우저의 localStorage에만 저장되므로, 다른 기기나 브라우저와는 공유되지 않아요. 옮기려면 `링크 공유`를 쓰세요.
